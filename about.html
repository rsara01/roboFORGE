About RoboForge

A robotics simulator that runs in your browser.

The project

Most of the work in robotics software is setup, so RoboForge runs entirely in the browser with nothing to install. It has a robot arm and a quadcopter.

What's inside

Render
Three.js + WebGL2
Arm physics
Custom rigid body + AABB stacking
Drone dynamics
Quadrotor + cascaded PID
Geocoding
OpenStreetMap Nominatim
Imagery
OpenStreetMap raster tiles
Elevation
AWS Mapzen Terrain Tiles
Audio
WebAudio (synthesized)
Scripting
Sandboxed JS host API

Open data acknowledgements

  • Map imagery: © OpenStreetMap contributors (ODbL).
  • Geocoding: Nominatim, run by the OSM Foundation.
  • Elevation: Mapzen Terrain Tiles, hosted by AWS Open Data.
  • 3D library: Three.js by mrdoob and contributors (MIT).

Drone export target

Missions export as DroneKit-Python scripts. Test them in ArduPilot SITL before flying a real vehicle.
